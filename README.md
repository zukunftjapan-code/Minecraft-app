# Minecraft-app

ブラウザで動く、Minecraft風の簡単なボクセル建築ゲームです。9歳のお子さんと一緒に遊べるレベルを目指しています。

## 遊び方

1. リポジトリをダウンロード（または `git clone`）します。
2. 簡易サーバーでこのフォルダを開きます（ブラウザの制限を避けるため、直接ファイルを開くより推奨します）。

   ```bash
   # Python がある場合
   python3 -m http.server 8000

   # または Node.js がある場合
   npx serve .
   ```

3. ブラウザで `http://localhost:8000` を開きます。
4. 「はじめる」ボタンを押してスタートします。

## 操作方法

| 操作 | キー |
| --- | --- |
| 移動 | W / A / S / D |
| 視点移動 | マウス |
| ジャンプ | スペース |
| ブロックをこわす | 左クリック |
| ブロックを置く | 右クリック |
| ブロックの種類を選ぶ | 1〜6 キー |
| マウスを離す | Esc |

画面右上の「🔄 リセット」ボタンで、いつでも新しい地形からやり直せます。作った世界はブラウザに自動保存され、次回開いたときも続きから遊べます。

## 技術構成

- 素のHTML/CSS/JavaScript + [Three.js](https://threejs.org/)（CDN読み込み）のみで、ビルド不要です。
- `index.html` : 画面のレイアウトとUI
- `style.css` : 見た目のスタイル
- `game.js` : 地形生成・操作・描画などゲーム本体のロジック
